# Guides

Each guide shows how to do one kind of task, with complete scripts you can run. If you haven't used the library yet, start with [your first script](/guide/getting-started).

## Tasks

| Guide | What's in it |
|---|---|
| [Search and browse the catalog](/guide/search-and-browse) | search then play the queue, lyrics, an artist's discography, daily chart snapshots |
| [Manage your library and playlists](/guide/library) | export liked songs, back up playlists, copy a playlist, remove duplicates, radio to playlist, mark as played |
| [Upload songs](/guide/uploads) | upload a folder of audio files |
| [Use it in a server](/guide/servers) | an HTTP search endpoint, concurrency and rate limits, serverless |
| [Test your code](/guide/testing) | a fake `fetch`, recording real responses |
| [Raw requests and responses](/guide/advanced) | any InnerTube endpoint, the mobile client, `nav`, streaming URLs |

## Setup
